# A 股综合候选

每天盘后独立扫描 P2、H1、趋势 1–4 和 HGB 稳健 Top3（23 因子重建）。查看 [最新报告](reports/latest.md) 或 [历史报告](reports/)。

- 北京时间交易日 16:50 启动，17:30 检查并补跑当天未完成或部分失败的任务。实际报告发布时间取决于 GitHub 排队和行情更新。
- 休市通过交易日历跳过。当日日线覆盖不足 95% 时标记工作流失败。
- 每路展示前 5 个，HGB 展示前 3 个，门控关闭时标为仅观察。P2 与 H1 的实际排名涉及次日开盘缺口。趋势 1 和 4 使用同一买入入口，分别展示。
- 仅生成候选观察报告。报告包含开盘复核条件和门控状态。历史涨跌停、成交资格和复权使用日线代理。
- 手动运行可在 Actions 指定北京时间交易日。首次报告可以用历史缓存生成，数据来源在 JSON 的 quality 中记录。
